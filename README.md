# AVENQIO QR

Site: https://avenqio-qr.onrender.com

Windows app: the `AVENQIO QR` portable executable is attached to the GitHub release.

Free QR code generator for websites, Wi-Fi, text, email, phone, contacts, WhatsApp, SMS, places, and calendar events. Custom colors, a center logo, transparent backgrounds, print frames, and PNG, SVG, or PDF export. Recent codes stay in the browser. Italian and English. No account, no backend.

**Tools that move you forward.**

Created by **ForgeGroup × AVENQIO**.

This project is still under construction. Updates are on the way.
