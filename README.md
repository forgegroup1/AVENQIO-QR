# AVENQIO QR

Site: https://avenqio-qr.onrender.com

Free QR code generator for websites, Wi-Fi networks, text, email addresses, and phone numbers. Custom colors, a center logo, and different styles. Export as PNG or SVG, or copy the image to the clipboard. Everything stays in the browser: no account, no backend.

**Tools that move you forward.**

Created by **ForgeGroup × AVENQIO**.

This project is still under construction. Updates are on the way.
